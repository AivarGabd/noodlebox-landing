# GitHub Pages landing

This folder contains a static landing page for GitHub Pages.

## Files

- `index.html` - main page
- `styles.css` - page styles

## How to publish from this folder

1. Push changes to your repository.
2. Open repository settings on GitHub: `Settings -> Pages`.
3. In **Build and deployment**:
   - **Source**: `Deploy from a branch`
   - **Branch**: your branch (usually `main`)
   - **Folder**: `/landing-page`
4. Save and wait for deployment.

After deployment, your URL will be:

- `https://<username>.github.io/<repo-name>/`

If this is a user site repository (`<username>.github.io`), URL will be:

- `https://<username>.github.io/`
